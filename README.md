# 바이브 코딩의 빈칸

AI 챌린저스 워크숍(2026-12-12)용 웹툰 + 실습 사이트의 배포본입니다. 사이트: [site/](site/)

- 바이브 코딩 실습: 웹툰 「주말 어디갈까」와 같은 순서로, 내 AI 도구에 말로 시키며 GitHub 을 씁니다.
- 확장판 「GitHub 직접 익히기」: [GitHub 첫걸음](https://github.studydev.com/)의 레슨(실습 교재 GitHub Skills(MIT) 한글판 skills-kr)을 같은 형식으로 담았습니다.
- 진행 기록은 브라우저(localStorage)에만 남고, 어디로도 보내지 않습니다.

이 저장소는 배포본이라 직접 고치지 않습니다. 원본에서 `node scripts/build-dist.mjs` 로 다시 만듭니다.
